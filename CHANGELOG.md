# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версионирование — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-11-14

Первый публичный релиз.

### Добавлено

- Цели тремя способами: генерация ИИ, библиотека пресетов, ручной конструктор шагов.
- Квесты по порядку с опытом, золотом, таймерами и редактированием.
- Энергия как суточный лимит, зелья, щиты заморозки и серия дней с восстановлением.
- Лагерь из четырёх построек, шесть эпох и эволюция с серверной проверкой.
- Магазин с ценами, зависящими от эпохи.
- Лиги по общему опыту и сезоны на 7 дней с наградами за топ-3.
- Друзья, поиск по ID и рейтинг среди союзников.
- Таймер фокуса с серверной сессией: сдать квест раньше времени нельзя.
- Промокоды с ограничением по сроку и числу активаций.
- Профиль с аватарами и статистикой.
- 22 SQL-миграции: RLS, серверная экономика, защита от накрутки.
- 90+ тестов: конфиги, SQL-инварианты, виджеты, офлайн-логика.
- Локальный шрифт Nunito и тёмная тема Material 3.

### Изменено

- Ключи Supabase и адрес ИИ-backend вынесены из исходников в `--dart-define`; шаблон — `env.example.json`.
- Публичная документация: README, `docs/`, лицензия MIT, правила участия.

### Безопасность

- `complete_quest_atomic` сверяет id игрока с `auth.uid()`.
- Экономика считается SQL-функциями, клиент не пишет профиль.
- Награды ограничены триггером `clamp_quest_rewards`, множитель серии ограничен +50%.
- Ключ подписи Android, `env.json` и токен статьи исключены из репозитория.
