# Статья и скриншоты

В репозитории лежат материалы для публикации обзора приложения в Telegraph. Код игры от них не зависит.

- **`docs/telegraph_article.md`** — опубликованная версия: 11 разделов, только функционал, со скриншотами. Её и правит скрипт публикации.
- **`docs/telegraph_article_full.md`** — полная версия на 13 разделов: в ней есть ещё «Промокоды» (с кодом `PRAXIS2026`) и «Аккаунт и данные», а две формулировки подробнее. Если эти разделы понадобятся, скопируйте файл поверх опубликованного и запустите публикацию снова.

Публикация в Telegraph одной командой:

```bash
python tool/publish_telegraph.py --dry-run   # посмотреть, что уйдёт на сервер
python tool/publish_telegraph.py             # создать или обновить страницу
```

Скрипт сам создаёт анонимный аккаунт при первом запуске и сохраняет токен в `docs/.telegraph_state.json`, при следующих — обновляет ту же страницу. В статье нет таблиц и заголовков первого уровня: Telegraph поддерживает только `h3`/`h4` и не умеет таблицы.

**Токен не коммитится.** `docs/.telegraph_state.json` перечислен в `.gitignore`: токен даёт право править опубликованную страницу. Если файл потерян, скрипт создаст новую страницу с новым адресом; старую можно удалить вручную.

Домен `telegra.ph` в России бывает недоступен без VPN — тогда скрипт не подключится ни для публикации, ни для загрузки картинок, и это блокировка, а не ошибка статьи.

## Скриншоты

В статье сейчас стоят полные адреса (`https://i.ibb.co/...`): скрипт вставляет их как есть и ничего не загружает. Локальные файлы в `docs/screenshots/` — исходники для README и для ручной замены картинок.

Если в метке указать относительный путь (`![подпись](screenshots/quests.jpg)`), скрипт загрузит файл на хостинг Telegraph и подставит адрес. Если файла нет, он остановится и назовёт его; `--skip-missing-images` публикует без недостающих.

Что снять и как оформить — в [screenshots/README.md](screenshots/README.md). Держите в кадре только тестовый аккаунт: ники и данные реальных игроков в публичной статье не нужны.
