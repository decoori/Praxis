# Скриншоты

Пять файлов с этими именами используются в README репозитория и как исходники для статьи. Формат — JPEG (расширение `.jpg`).

| Файл | Экран | Что должно быть видно |
|---|---|---|
| `quests.jpg` | вкладка «Квесты» | шаги: выполненный, активный, заблокированный |
| `camp.jpg` | вкладка «Лагерь» | эпоха, прогресс, постройки, кнопка эволюции |
| `league.jpg` | вкладка «Рейтинг» | лига, место, конец сезона, награды за топ-3 |
| `shop.jpg` | вкладка «Магазин» | казна и товары с ценами |
| `profile.jpg` | вкладка «Профиль» | сводка, аватар, союзники |

`tool/publish_telegraph.py` подставляет картинки, если в статье указан относительный путь вида `![подпись](screenshots/файл.jpg)`. Сейчас в статье стоят внешние адреса, поэтому скрипт их не загружает.

Хотите больше — добавьте строку `![подпись](screenshots/файл.jpg)` в `docs/telegraph_article.md` там, где картинка уместна. Ставьте её **после списка, а не внутри**: строка с картинкой разрывает список на две части.

## Как снимать

- **Тёмная тема включена** — приложение тёмное, скриншоты должны совпадать.
- **Обрежьте строку состояния.** Часы, оператор, заряд батареи и уведомления в статье выглядят мусором, а уведомления могут выдать лишнее.
- **Никаких чужих данных.** Ники других игроков и email в профиле закройте или снимите на тестовом аккаунте: статья и README публичные.
- Ориентация книжная, как на телефоне. Telegraph сам растянет картинку по ширине страницы, поэтому размер подгонять не нужно.
- Формат — PNG или JPEG, имя файла строго как в таблице, расширение должно совпадать с реальным форматом.

## Текущий набор

Скриншоты в репозитории сняты на тестовом аккаунте с отладочными данными (крупная казна и опыт). Для статьи это нормально; для магазина приложений лучше переснять на аккаунте, похожем на настоящий прогресс.

## Публикация

```bash
python tool/publish_telegraph.py --dry-run             # покажет, какие картинки найдены
python tool/publish_telegraph.py                       # загрузит их и опубликует
python tool/publish_telegraph.py --skip-missing-images # опубликовать без недостающих
```

Если картинки нет на диске, скрипт остановится и назовёт её — до того, как что-либо загрузит. Молча публиковать статью без скриншота он не станет, чтобы не осталось пустых рамок.

**Картинки можно не отдавать Telegraph.** Если в метке указать полный адрес, скрипт вставит его как есть и загружать ничего не будет. Тогда скриншоты живут на вашем хостинге, и вы можете заменить их, не перепубликовывая страницу.

Домен `telegra.ph` в России бывает недоступен без VPN — тогда загрузка не пройдёт, и это блокировка, а не ошибка скрипта. Запасной вариант: добавить картинки вручную в редакторе Telegraph уже после публикации.
